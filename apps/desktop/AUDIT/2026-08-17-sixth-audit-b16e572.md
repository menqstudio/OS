## E — what was not checked at all

The fifth round's most valuable finding was here, and so is this one.

**Nobody opened the palette.** This round rebuilt the ⌘K modal's focus trap, added 6 tests, wrote a
document-level handler and a mousedown guard, and reasoned in comments about "the panel's padding"
and "a scrim that covers the page" — while the panel has no padding and the scrim covers nothing, and
has not since 2026-07-28. Two audits examined this component (the fifth round drove it with trusted
CDP input, and so did I) and both probed the mechanism rather than the rendering. T-024 names the gap
in the abstract; it did not occur to anyone to point a browser at the one surface the round was
working on. Nineteen days, three PRs touching the file, 33 green checks per PR.

**Nothing checks that a class the app applies is styled by anything.** The fifth round found dead CSS
(rules with no markup). This is the inverse — markup with no rules — and no gate looks for it in
either direction. `check_c1_tokens` verifies that every `var(--x)` resolves; nothing verifies that
`.palette-item.active` resolves. Both defects are one query apart and only one has a gate.

**`layout.css` is imported and never read by anything.** `Shell.tsx:2` imports it; its command-palette
section was deleted in PR #47 and the rest was never audited for the same fate. No test, gate, or
bundle check would notice if the whole file were empty.

**The `tools/` sweep was done forward, not backward.** The round confirmed its four new test files
were named in a workflow. It did not ask the complementary question — which existing test files are
named nowhere — and `test_renderer_broker_schemas.py` has been answering "none" for some time
(`A-12`).

**`validates()` was never mutated.** Every other check in `check_schema_mirrors.py` has a mutation
behind it and all four survive attack. The one function whose docstring makes the strongest claim
("made the rule stronger") is the one with no mutant, and five different mutations pass it (`A-02`).

**The `animation_clobber` fix was never attacked with the remedy it recommends.** The gate was
mutation-tested against the shorthand it was built for and not against the longhand its own error
message proposes — which reproduces the bug byte for byte (`A-03`).

**`save_ask_to_knowledge` was never run in the only configuration that can reach it.** The tests mock
the boundary; the governed path is blocked on every shipped install; the ungoverned path is the sole
live caller and nothing exercises it, so the provenance string has never been read in the situation
it describes (`A-05`).

**A concurrent session is building T-024's browser harness right now, unaudited, by the Builder whose
gates this report just holed.** `vitest.browser.config.ts`, `computedStyle.ts`, `browser-setup.ts` and
`pages.browser.spec.tsx` appeared in the working tree between 01:13 and the close of this run. That is
